## Top findings

1. **Remote dictionary words execute HTML in the retained web app** `[moderate]` — `apps/web/www/index.html:460` — Mutable upstream dictionary entries reach executable `innerHTML` sinks. Render words as text and bundle or pin the dictionary. *(adv)*
2. **Correction can overwrite text in a different editor field** `[significant]` — `native/main.swift:673` — Recapturing a destination preserves correction state, allowing an old prediction to replace matching text that the app never inserted into the new field. Bind correction to its original application and AX element. *(data-int)*
3. **Activation tests exercise the retired detector rather than production click policy** `[moderate]` — `native/Core.swift:171` — A mutation changing both production contact-count checks from three to two still passes every self-test. Test actual contact-count and mouse-pair consumption behavior and remove the misleading retired implementation. *(test, hyper, naive)*
4. **Packaged installation conflicts with the preserved app path and helpers** `[moderate]` — `native/package.sh:18` — Packaging installs `TrackpadSwipe.app`, while development installation and both helpers use `~/Applications/TrackpadType.app`; helpers can launch an old copy or fail. Preserve the required compatible installation path or implement an explicit migration. *(conventions)*
5. **Accessibility RPCs block the global event-tap callback** `[significant]` — `native/main.swift:687` — Synchronous calls into an unresponsive editor block input interception and the UI/heartbeat, risking event-tap timeout and capture cancellation. Move bounded validation behind an asynchronous pending-action boundary. *(thousand)*

## Critical

- **Remote dictionary words become executable HTML in the retained web app** `[moderate]` — `apps/web/www/index.html:460` — The web app fetches a dictionary from an independently maintained repository's mutable `master` branch (`:106`, `:431–434`) and interpolates predicted words into `innerHTML`; committed words enter another sink at `:464`. The engine accepts arbitrary nonempty word strings (`crates/swipe-engine/src/types.rs:45–55`) and returns the original strings through WASM. An upstream dictionary writer can provide an HTML event-handler payload as a word with a numeric frequency, causing execution in the deployed demo's origin when it becomes a prediction. This is a security vulnerability in the retained `make web-build` application, separate from the native package. Use text nodes/`textContent` in both sinks and bundle or pin the dictionary. *(adv; calibrated from Important to Critical for demonstrated script injection)*

- **Bind correction ownership to the original text element** `[significant]` — `native/main.swift:673` — A prediction click calls `captureTarget()` when the original destination loses focus, replacing `focusedElement` while retaining `lastCommit` and `expectedCaret` (`:563–573`). `replaceLast` validates only the newly captured element's caret and matching text (`:609–621`). After inserting `hello ` in field A, focusing field B that already contains `hello ` at caret position 6 and clicking an alternate prediction overwrites B's existing text. Application changes also clear the destination without clearing correction state (`:227–233`). Store the committed AX element/application with correction state, require that exact destination, and clear correction state whenever the target changes; do not recapture a destination for an old prediction. *(data-int; calibrated from Important to Critical for destructive replacement of unrelated user text)*

## Important

- **Test the actual activation and event-consumption policy; retire the unused detector** `[moderate]` — `native/Core.swift:171` — Gesture assertions exercise `ThreeFingerTap` (`native/Core.swift:58`), although runtime activation uses physical mouse-down/contact-count checks (`native/TrackpadBridge.c:76–78`, `native/main.swift:657–658`) and explicitly ignores touch-only activation. An external mutation harness changed both production checks from three contacts to two while every executable self-test, including “PASS: gestures,” still passed. Add deterministic tests using synthetic contact counts and mouse down/up sequences: require three contacts, reject other counts and touch-only sequences, and consume both click halves when opening and closing. Remove or clearly archive the unused detector and its tests, remove unused duration/movement defaults, and preserve the `threeFingerTap` preference read required for migration. Update historical test wording so maintainers do not tune a detector that cannot affect production. Hardware checks remain separate validation. *(test, hyper, naive)*

- **Preserve the existing installation path in the packaged upgrade flow** `[moderate]` — `native/package.sh:18` — Packaging introduces `TrackpadSwipe.app` and a `/Applications` drag target (`native/package.sh:38`, `docs/INSTALL.md:9–12`), while `AGENTS.md:6` requires preserving the installed `TrackpadType.app` path and `native/build.sh:10` installs to `~/Applications/TrackpadType.app`. Both helpers explicitly launch that older path (`native/trackpadswipe:5`, `native/trackpadtype:5`). Following distribution instructions can leave the helper launching an older development copy or failing after its removal. Preserve the required filename and compatible existing-user destination, align the helpers, and document any intentional migration policy. A fresh Accessibility grant alone does not resolve the path mismatch. *(conventions)*

- **Keep remote editor calls outside the global event-tap callback** `[significant]` — `native/main.swift:687` — Starting a stroke synchronously invokes `validTarget()` and potentially `captureTarget()`, which perform Accessibility RPCs against another application (`:563–579`). Command and correction clicks also perform RPCs before returning. These calls execute inside the global event-tap handler (`native/TrackpadBridge.c:96–99`) on the main run loop (`:117`). A slow editor blocks interception and the UI/heartbeat together, allowing ordinary editor latency to trigger event-tap timeout and cancel capture; no Accessibility messaging timeout is configured. Consume the relevant click promptly, perform bounded destination validation on a dedicated queue, and apply the action only if the session and destination still match. Keep synchronous tap decisions cached and ensure release remains responsive independently of editor RPCs. *(thousand)*

## Minor

- **Replace obsolete viewport tests with checks of the production screen conversion** `[moderate]` — `native/Core.swift:41` — `KeyboardGeometry.viewport` hard-codes the original 16-point inset and 58-point vertical offset and is used only by the alignment self-test (`:207–212`). Production uses measured `SuggestionLayout` geometry and a separate screen conversion (`native/main.swift:69–70`, `:628–632`), including offsets that change with suggestion width and wrapping. The self-test immediately round-trips each point through a transform and its inverse, so a wrong origin or size cancels out. Extract and use the production conversion, remove the unused factory, and test independently specified screen points and expected keys across narrow/wrapped layouts and offset displays. This consolidates both the maintenance trap and the ineffective alignment assertion. *(future, hyper, test)*

- **Preserve pasteboard item boundaries when restoring the retained app's clipboard** `[moderate]` — `apps/mac/Sources/SwipeTypeMac/Services/TextInsertionService.swift:26` — The retained app flattens original pasteboard items into `(type, data)` pairs, then restores them through repeated `setData` calls (`:49–53`). Multiple items exposing the same type collapse into one item, losing copied objects after swipe insertion. Preserve one `NSPasteboardItem` per original item and restore the collection with `writeObjects`. This affects the separately runnable retained app. *(data-int)*

- **Make the dictionary word-length limit an explicit UI contract** `[moderate]` — `native/main.swift:421` — Screen-fit reservation assumes predictions never exceed 22 characters, matching independent literals in `PathDecoder` (`native/Core.swift:104`), the generator (`native/tools/generate-dictionary.py:22`), and validator (`native/tools/check-dictionary.py:16`). Increasing vocabulary length can invalidate reserved popup height and move or clip the keyboard during predictions. Reuse a named supported maximum for the decoder/UI and check its relationship to generation/validation, or derive reservation from the loaded dictionary's maximum length. *(future)*

- **Clarify that the session's “capturing” phase is distinct from pointer capture** `[moderate]` — `native/Core.swift:84` — Lifting activation contacts enters `.capturing`, although showing the panel calls `TPSetCapture(false)` (`native/main.swift:533`). The phase persists between words and during final prediction, while `ClickStroke.active` and `TPIsCapturing()` track actual capture. Status JSON can therefore report `phase: capturing` and `capturing: false`, inviting incorrect lifecycle assumptions. Rename the phase to `.ready`/`.visible`, or document the distinction at the enum and status schema and identify authoritative stroke/capture state. *(naive)*

- **Document the native release version authority** `[moderate]` — `scripts/sync_version.sh:9` — The unqualified version command reads root `VERSION`/`BUILD_NUMBER` and updates retained Xcode/Rust projects, while native packaging independently reads `native/Info.plist` (`native/package.sh:20`). Root version/build are `0.1.4`/`9`; native version/build are `0.2.0`/`5`. A maintainer following the apparent version targets can ship an unchanged native version. Label retained-app commands as upstream-only and document both native plist fields in `docs/RELEASING.md`, or provide a native version command with one explicit source of truth. *(naive)*
