# TrackpadSwipe 0.2.0 — public preview

Release notes prepared for build 13. The owner reports live testing and clean-install testing passed on 2026-10-22. This release is not published: Developer ID signing/notarization and a non-GitHub download host remain outstanding.

TrackpadSwipe is a floating swipe keyboard for macOS 15 or later. Rest three fingers on the trackpad and physically click to open it beside the pointer, click a starting letter, trace a word, then click again to type. Touching alone does not activate the keyboard.

## Included

- Live suggestions while tracing; the final click runs a complete-word match. Contractions preserve apostrophes.
- Fn opens numbers/punctuation for single-click entry; ABC returns to letters. On-screen delete removes a word or selected text.
- Conditional spaces before words: no space for the first word or after a hyphen or whitespace; no automatic trailing space.
- Keyboard size from 50–400%, position presets/custom placement, and adjustable sensitivity.
- Independent suggestion fonts and sizes, fixed suggestion widths, and extra lines for long words.
- Blue typing cursor with dot/ring/crosshair/hidden choices; the ordinary pointer hides over the keyboard.
- Optional shortcut, URL, and command triggers for external tools.
- Codex and Telegram Desktop use process-targeted typing; corrections require the original field, caret, and exact previous text.
- Universal Apple silicon/Intel app bundle, DMG/ZIP packaging, illustrated installation guide, and an illustrative typing GIF.

## Installation

Download hosting is not yet announced. Packages will not be distributed through GitHub. Use the DMG to drag TrackpadSwipe.app into Applications, then enable it in System Settings → Privacy & Security → Accessibility. See the [illustrated setup guide](https://github.com/abwagner/TrackpadSwipe/blob/main/docs/INSTALL.md). Source builds remain supported.

The app code is MIT-licensed; the wordfreq-derived dictionary is separately CC BY-SA 4.0. Attribution and dictionary provenance are bundled. No telemetry, network typing service, or clipboard insertion is used.

## Known limitations

This is experimental software. Pointer capture covers all pointing devices during a stroke. Trackpad detection uses an undocumented Apple framework and the default trackpad; macOS gestures and external devices need compatibility testing. Intel slices compile but have not been tested on Intel hardware. Editor support varies. Codex and Telegram receive process-targeted typing: focus changes inside either app between validation and asynchronous event delivery remain possible. A remote write already in progress cannot be revoked. Synthetic matching benchmarks do not establish human accuracy.
